Move the cursor with the buttons (or click a word), change the options on the right, and slow it down to see each move. The code under the panel is the options object for what you see.

<Playground />

Things to try:

- **4× slower** and **word →**: the leading edge reaches the next word first, then the trailing edge catches up.
- **next line**: the same stretch, vertically, while the cursor glides along the line.
- **other column**: the sentence outline cannot morph between columns, so it fades through nothing.
- **ease-out back**: an overshoot reads as playful; a reader usually wants the default.
